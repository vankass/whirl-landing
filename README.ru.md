# 🚀 Whirl Landing

🇬🇧 [English version](README.md)

Простая адаптивная landing page, созданная для практики вёрстки и работы с современными веб-технологиями.

Проект разработан с использованием **HTML5**, **SCSS** и **JavaScript** с применением методологии **BEM**.

## 🚀 Особенности

* Адаптивная вёрстка страницы
* Семантическая HTML-разметка
* Стилизация с использованием SCSS
* Организация CSS-классов по методологии BEM
* Корректное отображение на различных размерах экрана

## 🛠 Технологии

* **HTML5**
* **SCSS**
* **JavaScript**
* **BEM**
